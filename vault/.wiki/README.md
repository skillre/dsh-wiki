# .wiki/ — Agent 私有状态区

本目录存放 agent 的**工作产物**，不承载正式知识内容：

| 内容 | 说明 |
|---|---|
| `index.json` | L2 检索索引（标题/别名/tag/摘要倒排，500+ 篇时启用） |
| `reports/` | 巡检报告：断链、孤儿、重复候选、过期内容 |
| `drafts/` | agent 起草中的中间文件（可随时删除） |

规则：
- agent 对 vault 的**读**可以遍及全库；**写**只允许 `inbox/` 与本目录（除非用户明确授权其他路径）。
- 本目录内容随 git 版本化（报告有历史价值），`drafts/` 可随时清空。
